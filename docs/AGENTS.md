# Documentation Scope Instructions

## Working technical spike

Zero-friction automatic runtime provisioning is a long-term ProjectForge
product requirement, but it is not part of the current working technical spike.

Do not expand the spike to download or install Ollama, models, repositories,
executables, or other system software. The spike may define and test shared
provisioning boundaries only. Concrete downloading, installation, caching, and
startup automation begins with the applicable provider or packaging milestone.
